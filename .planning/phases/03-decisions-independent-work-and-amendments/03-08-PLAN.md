<objective>
The host side of pause and resume (D-08, AUT-1, AUT-5; research Pitfalls 2 and 4). Three gaps keep the live pause and resume from working: the launch builder always emits `--session-id` (the CLI refuses it together with `--resume`) and the reap matches only `--session-id`; the stream parser drops the result text, so a host outcome never carries a `question`; and the unit prompt never tells the model which choices it must stop and ask about. This plan closes all three offline. Vendor flags stay in the adapter; the port gains only a vendor-neutral field.

Purpose: the pause can be seen and the paused session can be resumed; spike S3-A (plan 03-13) then measures it live.
Output: port field, launch-line branch, reap pattern, final-text tail, prompt builders, tests on the claude replay fixture.
</objective>
