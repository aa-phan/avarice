| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-44 | Elevation of privilege | a LaunchAgent that runs an attacker-chosen program | high | mitigate | fixed template; ProgramArguments are the absolute, existing Node binary and CLI entry of the running install; values validated and XML-escaped; plutil lint before load |
| T-03-45 | Tampering | install overwriting or remove deleting a file AVARICE did not write | medium | mitigate | marker check; lstat refuses symlinks; temp file and rename; refusals write nothing |
