<objective>
Park and unpark for a paused item (AUT-3; research Pitfall 1). With items running in one clone (D-09), a paused item B leaves source edits and its `.planning/quick/<id>` records in the tree while item C runs: C's checks would run on B's half-done code, and C's commit cleanup would delete B's PLAN. Park takes B's delta out of the tree and keeps it reachable by a ref; unpark puts it back on top of C's commit before B resumes, or reports a conflict so the stage can open a decision instead of overwriting.

Purpose: independent work continues on a clean tree, and the paused session finds its records when it resumes.
Output: three RunWorkspace methods in port and git adapter, a real-git integration test.
</objective>
