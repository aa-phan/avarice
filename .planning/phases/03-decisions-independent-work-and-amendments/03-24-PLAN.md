<objective>
Safe cancellation of a multi-item run (AUT-12, owner decision 3). No cancel command exists: `cancelled` is never entered and nothing withdraws a decision for a cancel. This plan adds `avarice cancel <run>` under the terminal identity rule, using the existing lease, fence and abort controller: a run with no live supervisor is cancelled directly; a run with one gets a cancel request the supervisor acts on.

Purpose: cancellation is safe at any point and every state stays visible offline.
Output: cancel service and command, supervisor and stage changes, integration and fault tests.
</objective>
