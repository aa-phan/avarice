<objective>
Item-local decisions with independent work continuing (D-09, D-16, AUT-1 to AUT-4, S-17). Today every block stops the whole run with an empty record. This plan splits blockRun into an item-local block (park the item, open a full record, keep going) and the run-wide block, adds the supervisor's block, release and re-check protocol and its pickup rule for a continuable blocked run, ends an undeliverable run as failed, and runs an answered item again as a fresh unit with the answer. Plan 03-22 adds the resumed-session path in front of the fresh unit.

Purpose: SC1's first half: a question on one item leaves independent items completed with evidence while dependents wait, and the run is visibly blocked without polling.
Output: blocked.ts and park.ts, item stage and supervisor changes, S-17 and park fault tests.
</objective>
