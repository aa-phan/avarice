<objective>
The ledger side of decisions (AUT-2, AUT-5) and the schema every later Phase 3 plan writes into. Today a decision can only be opened (findings.md: answered, stale and withdrawn are unreachable). This plan adds migration 0003 and the three decision state changes, each one ledger transaction under the run lock, plus the per-item attempt key that every multi-item stage needs.

The `decide` command (plan 03-20) validates identity, option and digest first (D-15) and then calls these methods; the ledger re-checks that the decision is still open and the contract version unchanged inside the transaction, so a racing answer or amendment cannot slip between validation and write.

Purpose: answered, stale and withdrawn become reachable, atomically. AUT-12 (cancel) later withdraws through withdrawDecision.
Output: migration 0003, port and adapter methods, an integration test file, upgrade test, every explicit migration list updated.
</objective>
