<assumption_delta_decision>
Pluralization: an exit run can now have several attempts. Until now the evidence file held one entry per brief, and authorize refused a brief it already recorded. Primary noun after this plan: the run role (`run1`, `run2`, `run3`) with an attempt number. Decision: promote. The role and the attempt become each entry's identity, and the brief digest is demoted to a detail of one attempt, so a redrafted brief continues the same run's count. Invariant test (Task 2): a run whose second attempt uses a new digest is still refused by the stop-loss after two failures.
</assumption_delta_decision>

<objective>
The exit tools' bookkeeping for D-26, D-27, D-29 and D-33. Each attempt of each run is recorded with its role and number. Every stop Claude classifies carries its evidence and the owner's ruling. authorize then enforces the order 2, 3, 1, starts a run only after the previous one's outcome is recorded, allows a re-run only on the owner's confirmed classification, and stops after two failed attempts of the same run.

Purpose: the re-run and stop rules of the replanned exit are mechanical, not left to an executor's reading. The run plans (03-57 to 03-59) express them as checkpoint branches, and this plan makes any other path refuse.
Output: the classify subcommand, startRefusal with its epoch rule, attempt fields, and their tests.
</objective>
