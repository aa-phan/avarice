<objective>
One redactor at the event and log boundaries (SEC-3, D-14). Today `appendEventRow` stores event data unredacted and the shell history writes typed lines as they are. This plan adds a domain `Redactor` over the existing secret patterns plus seeded literals, a process-wide instance that the lean hook entry can load, redaction of every event string leaf before it is hashed, and redaction of shell history lines.

Purpose: the redaction suite (plan 04-22) finds 0 secret patterns in events (AC-5); the credential broker (plan 04-15) seeds the same instance.
Output: domain redactor, process instance, two boundaries, tests.
</objective>
