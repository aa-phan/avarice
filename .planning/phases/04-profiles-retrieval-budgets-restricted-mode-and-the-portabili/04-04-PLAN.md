<objective>
Profile selection and repository binding (SEC-1, D-16, D-17, D-18). Today `DEFAULT_PROFILE` is hard-coded and `--profile` is accepted only as personal-local. This plan makes the profile a selected identity: a name grammar and class, a precedence of binding, flag, AVARICE_PROFILE and default decided in main() before any store is opened, a binding registry written by `repo add --profile`, and refusals for a mismatch and for an enterprise remote under a personal profile.

Purpose: AC-6 (0 cross-profile reads) starts here: a wrong profile reads nothing.
Output: domain profile module, binding adapter, threaded selection, tests.
</objective>
