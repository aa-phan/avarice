<objective>
Profile propagation and moved-root isolation (SEC-1, D-16, D-19). The detached supervisor and launchd carry only the three root variables, so a selected profile is lost in a child; and a profile whose roots were moved by environment variable stays readable to other profiles' runs (docs/system/containment.md:468). This plan carries the profile name to every child, discovers every known profile's roots, and denies them in every run sandbox.

Purpose: AC-6 requires 0 cross-profile reads, including moved roots.
Output: profile registry adapter, scope and executor deny lists, propagation, tests.
</objective>
