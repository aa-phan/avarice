<objective>
Host admission as a patch range with a launch self-check (D-20, OPS-6). `ADMITTED_CLAUDE_VERSIONS` is a list that grows only after a live run per patch; the owner judged that friction larger than the risk. This plan replaces the list check with a pure predicate (verified, unverified patch inside a verified minor, refused), runs the offline probes before launching an unverified patch, labels the descriptor, and records the decision as ADR-014.

Purpose: patch upgrades of Claude Code stop blocking contained runs, while a new minor or a failed probe still refuses.
Output: domain predicate, preflight change, ADR, tests.
</objective>
