<objective>
Credential broker (SEC-2, ADR-009, D-17). No CredentialProvider port exists and nothing produces the `unauthenticated` error. This plan adds the reference grammar with the env refusal, the port with a value-scoped handle, the keychain, cmd and delegated adapters, the app service that records a value-free credential.resolve event for every attempt and seeds the redactor, and the per-profile provider allow-list wired into AppDeps.

Purpose: credentials are resolved by reference at the moment of use from an approved provider and never persisted.
Output: domain grammar, port, three adapters, app service, composition, tests.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-37 | Information disclosure | credential value in an event, artifact or log | high | mitigate | value-free credential.resolve; handle exposes the value only inside use(); redactor seeded before return; dump test |
| T-04-38 | Elevation of privilege | arbitrary helper execution through cmd: | high | mitigate | helper must be in credentials.helpers; argv only; sandboxed executor; scrubbed environment; timeout |
| T-04-39 | Spoofing | env: or an unapproved provider used as a source | medium | mitigate | grammar refuses env:; class allow-list; composition refuses an env: reference |
| T-04-40 | Information disclosure | secret in a process argument list | medium | mitigate | the service name is the only argument; the value arrives on stdout only |
