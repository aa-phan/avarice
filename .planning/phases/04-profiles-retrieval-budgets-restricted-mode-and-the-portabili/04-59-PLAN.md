flagged_assumptions:
  - "GWR-05: the lock's startedAt is the time the holder wrote the lock (withBindingsLock writes new Date().toISOString()). A lock naming a live PID is stale when the process now holding that PID started more than 2 seconds after startedAt: it cannot be the writer that created the lock. The start time is read as now minus the elapsed time `ps -o etime= -p <pid>` prints (`[[dd-]hh:]mm:ss`, no locale or time zone involved), with `ps` run from /bin/ps (or /usr/bin/ps when that is the one present) and a fixed minimal environment. The 2-second margin covers the whole-second resolution of etime and the gap between spawn and the lock write."
  - "When the start time cannot be read (no ps, a parse failure, a non-zero exit), a lock naming a live PID is stale only when its file is older than BINDINGS_STALE_AGE_MS (60 seconds, far above one registry rewrite); otherwise it is held, as now. The residual (a live but hung original holder taken over after 60 seconds when ps is unavailable) is named in the SUMMARY."
  - "The staleness rule is a pure exported function so its edges are unit-tested without planting processes; one fault test plants a real live PID with an hour-old startedAt."
  - "GWR-06: a present-but-corrupt config (kind invalid: bad JSON, a refused key, a link, oversize) of another profile gets its whole root denied, as a permission refusal does. The skip stays only for a directory that is not a profile (not a directory, not a valid profile name) and for the selected profile's own entry."
  - "GWR-07 is a test-only fix with the 04-47 discipline: the race tests retry only the evidence of a race (up to 5 attempts) and keep the exactness assertions on every attempt; the discriminating variant runs the same race through an unlocked read-add-rename written in the test helper (never exported from src) and must lose a binding."

Close three gaps in the profile registry and its lock: GWR-05 (a bindings lock left by a crashed writer is never taken over once its PID is reused, so every binding write fails), GWR-06 (a corrupt profile config is skipped, so that profile's roots stay readable to other profiles' sandboxed commands) and GWR-07 (the bindings race test never shows the two writers overlapped).

Purpose: profile isolation and binding (SEC-1, D-16, D-19) hold under crashes, corruption and concurrency.
Output: a start-time staleness rule for the lock, whole-root denial for a corrupt config, and race tests that prove the race was run.
</objective>
