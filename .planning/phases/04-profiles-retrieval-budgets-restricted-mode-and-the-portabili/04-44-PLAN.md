<objective>
Close two restricted-mode warnings and one promotion warning (WR-12, WR-13, WR-22). A restricted run's patch is never checked against the contract's write scope although the owner is told to apply it; an unreadable or oversize output from the uncontained host aborts the stage after the host ran, and every resume launches the host again; and the promotion path check admits a `.git` segment at the one boundary that writes into the owner's checkout.

Purpose: restricted mode (CON-4) hands the owner only what the contract allowed, ends cleanly when the host misbehaves, and promotion (ONB-6) cannot plant a repository in the owner's checkout.
Output: scoped restricted patch, outputs treated as findings, strict promotion paths.
</objective>
