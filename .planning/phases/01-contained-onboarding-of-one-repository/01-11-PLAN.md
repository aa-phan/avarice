Generate everything a contained invocation is launched with, from the onboarding contract: the vendor-neutral scope, the Claude Code settings, the environment, the launch argv, the agents file, the skills plugin, and the fail-closed launch preflight, after the owner picks the Bash permission strategy with S0-A evidence.

## Phase Goal

**As a** solo developer, **I want to** onboard one existing repository into AVARICE, **so that** later unattended runs start from an active project record with a code-and-document graph.

Purpose: containment must not depend on the model behaving (core value). These generators encode the spike decisions (`--setting-sources ""` plus `--plugin-dir` and `--agents`; `denyWrite` for every out-of-scope existing entry because cwd is always writable; nothing under `~/.claude*`) and make SC3 ("with the hook removed, the generated settings missing or the sandbox unavailable, onboarding stays blocked") enforceable before launch.
Output: pure scope computation, Claude adapters for settings, env, argv and preflight, GSD agents and plugin generators, SEC-5 checks.
</objective>
