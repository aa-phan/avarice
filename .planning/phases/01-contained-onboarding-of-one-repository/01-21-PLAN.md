## Phase Goal

**As a** solo developer, **I want to** onboard one existing repository into AVARICE, **so that** later unattended runs start from an active project record with a code-and-document graph.

Purpose: a supervisor SIGKILLed during the intel or knowledge invocation leaves its detached host running; today `resume` relaunches beside it (`reconcileInvocation` handles only `launch:map` and returns early outside `mapping`/`paused`), so the survivor can still write `.planning/intel/**` or `.avarice-knowledge/.extraction/**` while AVARICE validates and snapshots. T-01-44 says relaunching beside a survivor is not an option.
Output: generic launch reaping in `resume.ts`, an exported session-ID reaper, a fake host that can die inside intel or knowledge with a survivor, two kill points and an in-process prelude test.
</objective>
