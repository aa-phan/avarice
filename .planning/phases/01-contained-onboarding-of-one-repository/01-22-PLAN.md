## Phase Goal

**As a** solo developer, **I want to** onboard one existing repository into AVARICE, **so that** later unattended runs start from an active project record with a code-and-document graph.

Purpose: the sandbox deliberately leaves the staging root writable ("entries created later at unlisted locations are caught by the staging diff gate, not prevented"), so this gate is the only control for that case, and the repository controls its own `.gitignore`.
Output: one git flag, one parser case, hostile-repository tests for both gates and positive controls.

Deviation from the gap text, on evidence: the gap and the review name `--ignored=matching`. A planning-time probe on git 2.39.5 (scratch repo, committed `.gitignore` of `*`, new files `evil.txt`, `evil/x.sh`, `.planning/codebase/STACK.md`, `src/b.ts`) printed `! .planning/codebase/`, `! evil.txt`, `! evil/`, `! src/b.ts` with `--ignored=matching` (an ignored directory collapses into one record that hides its files, and `.planning/codebase/` would even be read by `extraMapFiles` as an extra map file), and one record per file with `--ignored=traditional` under `--untracked-files=all`. This plan therefore uses `--ignored=traditional`; the test pins the per-file listing.
