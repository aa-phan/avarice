## Phase Goal

**As a** solo developer, **I want to** onboard one existing repository into AVARICE, **so that** later unattended runs start from an active project record with a code-and-document graph.

Purpose: success criterion 1 requires the graph to list code nodes and document nodes (ONB-14); the spike showed `merge-graphs` severs every document-to-code edge and drops `built_at_commit`, so AVARICE owns the merge (owner decision 2026-11-01).
Output: corpus selection and materialization, knowledge step, merge, validation, record knowledge fields.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository documents → knowledge invocation | Document text reaches a model with tool access |
| skill graph → merged graph | Model-inferred nodes and edges join deterministic code nodes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-52 | Elevation (prompt injection) | knowledge invocation | high | mitigate | Write root `.avarice-knowledge` only, no network, hook and sandbox, no credentials; contract and settings digests asserted unchanged with an injected ADR (S-46) |
| T-01-53 | Tampering (graph poisoning) | src/domain/graph-merge.ts | high | mitigate | Confidence tiers kept, never upgraded; document edges must be INFERRED or AMBIGUOUS; provenance per node; size cap; dangling and AST document edges dropped and counted |
| T-01-54 | Information disclosure | merged graph.json | high | mitigate | Secret scan over the merged JSON blocks install; corpus excludes secret-bearing paths and oversized files |
| T-01-55 | Denial of service | knowledge pass budget | low | accept | Bounded by the knowledge wall-clock share, invocation and subagent budgets; failure keeps the code-only graph and activation proceeds |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No installs; the graphify skill runs with the preinstalled interpreter and no network, so its install step cannot fetch |
</threat_model>
