<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user repository config and hooks → git subprocesses | Hooks, fsmonitor, system config and attributes are repository- or machine-controlled |
| user checkout files → preflight | Untracked secrets sit next to tracked files |
| staging workspace → user .git | A worktree shares the user's object store and refs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
