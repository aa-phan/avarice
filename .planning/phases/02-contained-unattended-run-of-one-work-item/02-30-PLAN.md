<objective>
Close three code-review findings of 02-REVIEW.md (triage group P5; item.ts holds two of them, so they stay together):
- R-IN-06 (IN-06): the unit's host gets `new AbortController().signal`, which is never aborted. A lost lease only sets `lease.lost`, read at the top of the stage loop after the unit returns, so a supervisor that lost its lease waits out the unit's wall clock and spends budget until the new holder reaps the host. Fix: an abort signal on the stage context, aborted from the lease-renewal failure branches. The unit uses it, and the stage stops before classification when it fired. The Claude host adapter already ends the process group on abort. The review called aborting on SIGTERM optional, and it is not added: a SIGTERM handler would change how an operator stop ends a supervisor. Today SIGTERM ends the process at once and the next resume reaps the host, the documented recovery path. With a handler, the stop would become a cancelled unit that the stage goes on to classify and retry, which needs its own design and an owner decision. Plan 02-35 records this reason with the disposition.
- R-IN-05 (IN-05): run-resume.ts `continue`s past a started launch when the host has no `reap` or the step has no session ID, contradicting its own invariant that a reap that cannot run stops the resume. Fix: return an error, recorded as the failed reconcile step.
- R-IN-08 (IN-08): reconcileGated accepts a moved HEAD on trailers alone. Fix: the commit's single parent must be the attempt's snapshot head (that also proves the range is one commit). HeadTrailers gains the parents, so no new port method is needed.

docs/system/containment.md is edited by plan 02-27 in the same wave, so this plan does not touch it. Its host paragraph says the caller passes an abort signal with the wall-clock timeout. If that sentence needs a run-specific addition, list it in the SUMMARY for plan 02-35.

Output: the signal plumbing, the two reconcile fixes, a new fault test, RED evidence, runs.md updated (reviewed fresh in plan 02-35).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| supervisor <-> ledger lease | Two supervisors can believe they own a run; the fence decides |
| detached host process -> clone and budget | A host can outlive the supervisor that started it |
