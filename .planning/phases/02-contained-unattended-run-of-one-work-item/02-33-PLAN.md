## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository code (checks, install, inventory, agent-written tests) -> the user's home directory | Runs under a sandbox that allows reads by default |
| sandboxed command -> scratch directory -> the next agent invocation | Scratch is writable to commands and readable to the model |
| check output -> artifact store -> owner | Output is stored and shown to the owner |
